## Notes

`cad/assembly.py` writes `artefacts/assembly.step`, `artefacts/placement.json`, and
`data/cad/assembly-full.step` (git-ignored, not committed).

Lid normal and stack axis are read off `box_shell`'s own +Z and +Y faces (found by
`Face.normal_at()`), then carried through the placement `Location`'s rotation via
`Vector.transform(Matrix(loc.wrapped.Transformation()), is_direction=True)` — the direction
form, so translation does not leak in. `Location * Vector` does not work in this build123d
version (it dispatches to `Vector.__rmul__`, which expects a scalar) — worth a note for
whoever next needs to transform a bare point or direction rather than a Shape.

Implementation note carried from WP-02: `Compound(children=...)` reparents child shapes into
whichever Compound last claimed them. `assembly.step`'s solid count and volume are captured
immediately after its `export_step()` call, before the same shell/motor/keepout objects are
reused inside `assembly-full.step`'s Compound.

WP-02's PR (#15) had already merged on GitHub before this session started, but the local clone
was 3 commits behind `main`; pulled before starting so `cad/enclosure.py` and `box-shell.stl`
were present.
